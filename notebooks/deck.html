01
Background

연구 배경 — 복합 극한기후란

  • 정의 — 폭염(고온) ∧ 가뭄(강수 부족)이 같은 시기·지역에 동시 발생
  • 왜 더 위험한가 — 피해가 단순 합이 아니라 곱셈적으로 증폭
  • 고온→증발산↑→토양 건조→지표 가열↑ 의 land–atmosphere 양의 되먹임
  • 결과: 농업 수확 급감·산불·수자원 고갈·열사병
  • 실재성 — 2003 유럽·2010 러시아·2018 동아시아(한반도 관측사상 최악)
  • 기후변화 — 온난화로 빈도·강도·지속 증가 (IPCC AR6 별도 위험 강조)
관측된 hot extremes·가뭄 변화 — IPCC AR6 WG1 SPM Fig.3

Labeling

라벨링 — 사건 판단 기준 (상대적 이상)

폭염 heatwave

그 격자·그 시기 p95 초과가 3일 연속 (doy ±7일 윈도우 → 계절·지역 편향 제거)

가뭄 drought

SPI-1 < −1 — 최근 30일 누적강수 하위 ~16% · 월별 gamma 적합으로 계절중립

복합 compound

동일 격자·동일 날짜 폭염 ∧ 가뭄 동시 = 단기 compound hot-dry

SPI 타임스케일 (UCAR) · 전기간 라벨 빈도 가뭄 15.65%·폭염 1.84%·복합 0.44%

08
★ Key Method

doy-아노말리 — 입력을 라벨 정의에 정렬

  • 문제 — 폭염 라벨은 평년 대비(doy-p95)인데 입력 t2m은 절대 온도장 → 기준 불일치
  • 해결 — t2m 평년편차(아노말리) 채널 추가
  • anom = 물리 t2m − doy 기후값(±7일) · Train-only → 누수 없음
  • 가뭄에서 입력창을 SPI 누적기간(30일)에 맞춘 것과 같은 원리
직관 — 같은 28℃라도
· 4월 평년 15℃ → +13℃ 이상고온
· 7월 평년 30℃ → −2℃ 정상

모델이 계절 기후표를 복원하지 않고 평년편차를 직접 입력받음

Training & Metrics

학습 프로토콜과 평가지표 원칙

불균형·과적합 대응

Pipeline B · 설계

하이브리드 윈도우 — 리드 1~15 분리

  • 문제 — 탐지기 윈도우 30일 vs GenCast 예보 15일 → 절대 비교 불가
  • 하이브리드 — 30일 창 = ERA5 과거(30−d) + GenCast 미래(d)
  • ERA5 29 + GenCast 15 = 44일 슬라이딩 → 리드 1~15 한 번에
  • 기준선 — perfect(ERA5·상한)·climatology(no-skill)·persistence(naive)
효율

GenCast 원본 추론(여름 90 init 6/15~8/24 × 8멤버 × 15일)은 재실행 없이 후처리만으로 평가.

아노말리 채널은 하이브리드에서 즉석 산출(저장 doy 기후값 재사용·저장본과 오차 0.0 검증).

★ Robustness ② · Persistence

엄밀화 ② — 순기여 분리 (persistence)

  • 질문 — 가뭄 "2주 skill"이 GenCast 기여인가, 단순 지속성인가?
  • 방법 — 미래를 직전 관측으로 hold한 naive 예보와 비교
  • 순기여 = (GenCast − persist)/(perfect − persist)

Conclusion

종합 결론

Pipeline A · 잣대 구축

입력을 라벨 정의에 정렬(doy-아노말리)해 폭염·복합 판별력 +60%/+43%, AUC 0.98 신뢰성 잣대.

Pipeline B · 예보 평가

운용조건에서 가뭄 ~2주·폭염·복합 ~1주 유지. 앙상블은 과신(under-dispersion).

순기여 (persistence 대비)

가뭄은 상당부분 지속성, 폭염·복합은 GenCast가 naive를 진짜 능가 → 서열은 절대 AUC 기준, 순기여로는 격차 좁아짐.

방법론 기여

탐지기를 Frozen 잣대로 쓰는 사건 단위 리드타임 평가 프레임 — 평균장 지표가 놓치는 tail/joint 예측성 진단.

결론
19
Limitations

한계 — 정직한 서술 (과대포장 금지)

  • 적용 범위 — 동아시아·1°·여름·Hot-Dry 전용 (범용 아님)
  • 평가 대상 — Frozen detector score와 ERA5 기준의 일치도 → 직접 예측성이 아님(탐지기 편향 전파)
  • 하이브리드 귀속 — 모든 리드가 ERA5 antecedent 포함 → persistence로 분해(완료)
  • 극희소성 — 복합 Test base ~0.8% → 절대 CSI는 통계적으로 어렵다(이론적 천장은 base 무관)
  • 확률 보정 미적용 · 라벨 기후정의 전기간 산출(retrospective·입력 통계는 Train-only)
